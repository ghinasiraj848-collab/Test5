دليل الربط وطريقة الاستخدام (بالدارجة المغربية)

1. كيفاش تربط الموقع مع Supabase؟

سير لـ موقع Supabase.com وفتح حساب مجاني. من بعد صاوب Project جديد. من إعدادات المشروع (Settings > API) غا تلقى جوج حوايج مهمين: Project URL و anon / public API Key. هبط لتحت في هاد الكود (في آخر الملف JavaScript) وحطهم بلاصة المتغيرات `SUPABASE_URL` و `SUPABASE_ANON_KEY`.

2. شنصاوب في قاعدة البيانات (Tables)؟

في لوحة تحكم Supabase (قسم SQL Editor)، خصك تنشئ 3 جدولات رئيسية:

  • products (id, title, price, stock, image, description)
  • orders (id, customer_name, customer_phone, customer_address, items, total, status, created_at)
  • settings (id, store_name, phone, whatsapp)

3. كيفاش ترفع الموقع على GitHub Pages؟

سدي هاد الكود كامل فملف سميتو index.html، وحطو بوحدو فـ Repository جديدة فـ GitHub. من بعد سير لـ Settings > Pages واختار الـ Branch لي هو `main` أو `root`. في دقائق معدودة غادي يعطيك الرابط ديال موقعك خدام 100% وفي أي بلاصة فالعالم!

4. معلومات الدخول للـ Admin وكلمة المرور

كلمة المرور الافتراضية للوحة التحكم هي admin123 (يمكن ليك تبدلها فالكود الفوق). التغييرات كاملة كاتحفظ مباشرة في Supabase داكشي علاش ما كاتضيعش نهائياً وخا تحل الموقع من أي جهاز آخر.
